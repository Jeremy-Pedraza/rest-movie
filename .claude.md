# Instrucciones del Proyecto

## Estructura de Documentación

**IMPORTANTE:** Toda documentación debe seguir esta estructura:

- `docs/master.md` - Índice principal y fuente de verdad
- `docs/temp/` - Archivos temporales (se pueden borrar)
- `docs/plans/` - Plan único actualizable
- `docs/checkpoints/` - Puntos de guardado por sesión
- `docs/insomnia/` - YAMLs de endpoints

## Reglas de Documentación

1. Siempre actualizar master.md cuando agregues archivos
2. Checkpoints deben referenciar al plan activo
3. Un solo plan activo que se actualiza
4. Context7 guarda en docs/
